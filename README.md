📱 Projeto: Conversor de Unidades (Kotlin)

🎯 Objetivo
Desenvolver um aplicativo Android utilizando Kotlin no Android Studio, com o propósito de converter valores entre diferentes unidades de medida: centímetros, metros, quilômetros e milhas.

🧩 Funcionalidades Principais
- O usuário digita um valor numérico.
- Escolhe a unidade de entrada e a unidade de saída através de spinners.
- Ao pressionar o botão "Converter", o aplicativo realiza a conversão e exibe o resultado na tela.

🛠️ Componentes da Interface
- EditText – Para inserir o valor a ser convertido.
- Spinner (2x) – Um para selecionar a unidade de origem e outro para a unidade de destino.
- Button – Aciona a lógica de conversão.
- TextView – Mostra o valor convertido.

🔄 Unidades Suportadas
- Centímetros (cm)
- Metros (m)
- Quilômetros (km)
- Milhas (mi)

🧮 Exemplos de Conversão
- 1 metro → 100 centímetros
- 10 milhas → 16.093,4 quilômetros
- 2500 centímetros → 0,0155 milhas

✅ Requisitos Técnicos
- Layout claro, funcional e responsivo.
- Uso de condições `when` ou lógicas matemáticas para conversão.
- Código bem estruturado e com comentários explicativos.
- Aplicativo leve e compatível com diferentes tamanhos e orientações de tela.
